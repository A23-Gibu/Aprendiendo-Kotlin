# Aprendiendo Kotlin

Ejercicios prácticos de Kotlin organizados por temas.

## Temas
- **T_01_Entorno_y_primer_programa**: Primeros pasos, variables y funciones básicas.
- **T_02_Lambdas**: Ejercicios de funciones lambda y de orden superior.
- **T_03_Colecciones**: Listas, conjuntos, mapas y secuencias.

## Requisitos
- Java JDK 17 o superior.
- IntelliJ IDEA.
